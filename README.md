# 📝 Notepad

A fast notes app built with React. Write notes, organise them with colours and pins, and export them as text files. Everything is saved in your browser.

**Live Demo:** <your-link-if-deployed>

![Notepad](screenshots/notepad.png)

## Features
- Create, edit and delete notes
- Pin important notes to the top
- Colour labels for each note
- Search and sort (Recent / A–Z)
- Live word count, character count and reading time
- Copy note or download it as a `.txt` file
- Focus mode for distraction-free writing
- Data saved with localStorage

## Tech Stack
React, Vite, CSS

## Run Locally
1. Clone the repo
2. `npm install`
3. `npm run dev`
